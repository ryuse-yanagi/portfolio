# Simple Icons Notice

本プロジェクトでは、ポートフォリオサイトからGitHubプロフィールへのリンクを表示するために、Simple Iconsが提供するGitHubのブランドアイコンを使用しています。

* **アイコン：** GitHub
* **配布元：** https://simpleicons.org/
* **公式リポジトリ：** https://github.com/simple-icons/simple-icons
* **使用目的：** ポートフォリオサイトから作者のGitHubプロフィールへのリンクを表示するため

## ライセンス

Simple IconsのプロジェクトはCC0ライセンスで公開されています。ただし、個々のアイコンには別途ライセンス条件が適用される場合があります。そのため、GitHubアイコンの個別のライセンス情報をSimple Iconsの公式情報で確認してください。

## 商標およびブランドガイドライン

GitHubの名称およびロゴは、GitHubの商標です。

本プロジェクトでは、GitHubプロフィールへのリンク先を示す目的に限ってGitHubのアイコンを使用しています。GitHubが本ポートフォリオを公認、推奨、または運営していることを示すものではありません。

GitHubのロゴの使用条件については、以下の公式ブランドガイドラインを参照してください。
